# SVG distribution

The canonical standalone files are under `generated/angular/{appearance}/{size}/{id}.svg` at repository root. No second editable copy is maintained here. `generated/inventory.json` lists every export and SHA-256.

The complete project ZIP includes all SVGs and sprites. This directory documents the SVG distribution surface; it is not a published npm package. An eventual npm SVG package should be generated from the same inventory, after naming and licensing are approved.
