# Changelog

## 0.1.0-beta.1

- Refactored the unpublished package around Remix behavior primitives and
  generated, visually empty Mix specs/stylers.
- Added the base `RemixDisclosure` primitive and composed plan, activity,
  execution, permission details, and answer sources from it.
- Added explicit `AgentMessageCollapsible` and static/lazy transcript APIs.
- Removed public behavior engines, animation constants, visual defaults, and
  other implementation/test seams.
- Hardened composer lifecycle/keyboard behavior, permission decision latching,
  answer streaming actions, and reader-aware transcript following.
- Co-located structural Agent specs and kept composed Remix control stylers
  unresolved so child hover, focus, press, and selected variants remain live.
- Added Material-free functional glyphs, exact semantic boundaries, status and
  busy announcements, configurable status/output labels, and shared live-edge
  behavior for transcripts, plans, and activity ledgers.
- Aligned functional glyph choices and utility-action hierarchy with the pinned
  BeUI benchmark, using Material-free Lucide icons.
