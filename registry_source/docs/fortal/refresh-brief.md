# Fortal design provenance

Leo Farias's 2026-10-29 design brief established Fortal as an independent,
Fortaleza-inspired design system with seven owned palettes, twelve-step color
roles, neutral Calçadão defaults, flatter components, shared focus styling, and
contrast targets in both modes.

The 2026-10-31 palette review replaced Mangue with Serra, an earthy olive
(`#6F7845`); moved Céu to sky blue (`#1A95D8`) and Caju to a cashew-fruit
orange-red (`#E76A32`); and assigned error roles a dedicated red (`#C92E3B`)
that is not a selectable accent.

The [accepted architecture decision](../../../ARCHITECTURE.md#fortal-owns-its-visual-contract-fortal-adr-0003)
records the rationale and scope. The [Fortal specification](../../specs/fortal.md)
owns current values, component decisions, and acceptance rules. Consumer API
changes and migrations are recorded in the [changelog](CHANGELOG.md).
