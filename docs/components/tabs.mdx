A tabbed interface component for organizing content into separate switchable panels.

## When to use this

- **Content organization**: Group related content into separate sections
- **Navigation**: Switch between different views or categories
- **Settings panels**: Organize settings into categorized tabs
- **Multi-step forms**: Break complex forms into manageable sections

## Basic implementation

<CodeGroup title="Basic implementation" defaultLanguage="dart">
```dart
import 'package:flutter/material.dart';
import 'package:remix/remix.dart';

class TabsExample extends StatefulWidget {
  const TabsExample({super.key});

  @override
  State<TabsExample> createState() => _TabsExampleState();
}

class _TabsExampleState extends State<TabsExample> {
  String _tab = 'tab1';

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      width: 320,
      height: 280,
      child: RemixTabs(
        selectedTabId: _tab,
        onChanged: (id) => setState(() => _tab = id),
        child: Column(
          mainAxisSize: MainAxisSize.max,
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            RemixTabBar(
              style: tabBarStyle,
              child: Row(
                mainAxisSize: MainAxisSize.max,
                children: [
                  RemixTab(tabId: 'tab1', style: tabStyle, label: 'Tab 1'),
                  const SizedBox(width: 8),
                  RemixTab(tabId: 'tab2', style: tabStyle, label: 'Tab 2'),
                ],
              ),
            ),
            const SizedBox(height: 8),
            Expanded(
              child: RemixTabView(
                tabId: 'tab1',
                style: tabViewStyle,
                child: const Text('Content for Tab 1'),
              ),
            ),
            Expanded(
              child: RemixTabView(
                tabId: 'tab2',
                style: tabViewStyle,
                child: const Text('Content for Tab 2'),
              ),
            ),
          ],
        ),
      ),
    );
  }

  TabBarStyler get tabBarStyle {
    return TabBarStyler()
        .padding(.all(4))
        .borderRadius(.circular(12))
        .color(const Color(0xFFF4F6FF))
        .border(.color(Colors.indigo.shade100));
  }

  TabStyler get tabStyle {
    return TabStyler()
        .padding(.horizontal(18))
        .padding(.vertical(10))
        .borderRadius(.circular(10))
        .color(Colors.transparent)
        .labelFontSize(14)
        .labelFontWeight(FontWeight.w600)
        .labelColor(Colors.indigo.shade600)
        .iconColor(Colors.indigo.shade500)
        .onHovered(
          TabStyler()
              .color(Colors.indigo.shade50)
              .labelColor(Colors.indigo.shade700),
        )
        .onSelected(
          TabStyler()
              .color(Colors.white)
              .border(.color(Colors.indigo.shade400).width(2))
              .labelColor(Colors.indigo.shade700)
              .iconColor(Colors.indigo.shade600),
        );
  }

  TabViewStyler get tabViewStyle {
    return TabViewStyler()
        .padding(.all(20))
        .borderRadius(.circular(14))
        .color(Colors.white)
        .border(.color(Colors.indigo.shade100));
  }
}
```
</CodeGroup>

## Shared indicator

Each tab paints its own selected style by default. Set `indicator` on the
`TabBarStyler` to draw one surface behind the tabs instead, such as a pill or
an underline, that glides to the selected tab. The indicator takes the
selected tab's bounds, so `margin` insets it and the decoration draws it. Leave
the tab's own selected background clear so only the indicator shows.

```dart
import 'package:flutter/material.dart';
import 'package:remix/remix.dart';

class PillTabs extends StatefulWidget {
  const PillTabs({super.key});

  @override
  State<PillTabs> createState() => _PillTabsState();
}

class _PillTabsState extends State<PillTabs> {
  String _selected = 'overview';

  @override
  Widget build(BuildContext context) => RemixTabs(
    selectedTabId: _selected,
    onChanged: (id) => setState(() => _selected = id),
    child: Column(
      children: [
        RemixTabBar(
          style: TabBarStyler()
              .direction(.horizontal)
              .padding(.all(4))
              .color(Colors.blueGrey.shade100)
              .indicator(
                BoxStyler().color(Colors.white).borderRadius(.circular(8)),
              )
              .indicatorMotion(
                AnimationConfig.springDescription(
                  mass: 1,
                  stiffness: 400,
                  damping: 36,
                ),
              ),
          child: Row(
            children: [
              RemixTab(
                tabId: 'overview',
                label: 'Overview',
                style: TabStyler().padding(.all(8)),
              ),
              RemixTab(
                tabId: 'activity',
                label: 'Activity',
                style: TabStyler().padding(.all(8)),
              ),
            ],
          ),
        ),
        const RemixTabView(tabId: 'overview', child: Text('Overview')),
        const RemixTabView(tabId: 'activity', child: Text('Activity')),
      ],
    ),
  );
}
```

`indicatorMotion` accepts two Mix `AnimationConfig` types: `CurveAnimationConfig`
(for example, `AnimationConfig.curve(...)` or `AnimationConfig.easeOut(duration)`)
and `SpringAnimationConfig` (for example, `AnimationConfig.springDescription(...)`).
Curves honor their delay, and springs may overshoot before settling on the tab.
`onEnd` runs once for a completed glide, not an interrupted or skipped one.
With no motion config, the indicator glides along `Curves.easeOutCubic` over
250 ms. Phase and keyframe configs throw `ArgumentError` when the bar builds.
The bar's own `animate` still controls style changes independently.

The indicator follows the painted bounds of the selected tab when it moves or
resizes, including translation and axis-aligned scaling. It jumps to the selection
when reduced motion is enabled, even during a glide. It's excluded from semantics
and hit testing. Omitting the indicator leaves the tabs' own selected styles in
charge; adding or removing it does not reset the tabs' focus or state.

Scroll around the bar, not inside it. Changes that only repaint inside a separate
repaint boundary are picked up the next time the bar paints. If the selected tab
disappears, the indicator is hidden; if the departing tab disappears, the indicator
jumps to the selection.

## Properties
### Widget Properties

#### `key` → `Key?`

Optional. Controls how one widget replaces another widget in the tree.

#### `child` → `Widget`

**Required**. The tabs content.

#### `controller` → `NakedTabController?`

Optional. Optional controller for managing tab state.

#### `selectedTabId` → `String?`

Optional. The identifier of the currently selected tab.

#### `onChanged` → `ValueChanged<String>?`

Optional. Called when the selected tab changes.

#### `orientation` → `Axis`

Optional. The tab list orientation.

#### `activationMode` → `NakedTabActivationMode`

Optional. Whether moving focus automatically selects the focused tab. Defaults to `NakedTabActivationMode.automatic`; use `manual` when selection should require explicit activation.

#### `enabled` → `bool`

Optional. Whether the tabs are enabled.

#### `onEscapePressed` → `VoidCallback?`

Optional. Called when Escape is pressed while a tab has focus.

### Styled Leaf Properties

`RemixTabBar`, `RemixTab`, and `RemixTabView` each accept their matching
`Remix*Styler` through `style` and an optional raw `Remix*Spec` through
`styleSpec`. A raw spec bypasses fluent style resolution.

#### `maintainState` → `bool`

Optional on `RemixTabView`. Whether the panel keeps its state while hidden. Defaults to `true`.


### Tab Bar Style Methods

Methods on `TabBarStyler` configure the tab-list container.

#### `container(FlexBoxStyler value)`

Configures the tab bar flex box style.

#### `indicator(BoxStyler value)`

Draws a shared surface behind the selected tab that glides between tabs.
`null` draws none.

#### `indicatorEffects(RemixBoxEffectsMix value)`

Adds paint layers behind the indicator, such as a shadow.

#### `indicatorMotion(AnimationConfig value)`

Sets how the indicator moves: a `CurveAnimationConfig` or `SpringAnimationConfig`.
Phase and keyframe configs throw `ArgumentError` when the bar builds. Omitting
the config uses `Curves.easeOutCubic` over 250 ms.

#### `alignment(Alignment value)`

Sets tab bar alignment.

#### `padding(EdgeInsetsGeometryMix value)`

Sets tab bar padding.

#### `margin(EdgeInsetsGeometryMix value)`

Sets tab bar margin.

#### `color(Color value)`

Sets tab bar background color.

#### `size(double width, double height)`

Sets fixed tab bar width and height constraints.

#### `constraints(BoxConstraintsMix value)`

Sets tab bar constraints.

#### `decoration(DecorationMix value)`

Sets tab bar decoration.

#### `borderRadius(BorderRadiusGeometryMix radius)`

Sets tab bar border radius.

#### `foregroundDecoration(DecorationMix value)`

Sets a foreground decoration on the tab bar.

#### `transform(Matrix4 value, {AlignmentGeometry alignment = Alignment.center})`

Applies a matrix transform to the tab bar.

#### `animate(AnimationConfig value)`

Configures implicit animation for tab bar style transitions.

#### `variants(List<VariantStyle<TabBarSpec>> value)`

Sets custom tab bar variants.

#### `wrap(WidgetModifierConfig value)`

Applies widget modifiers to the tab bar.

#### `call({Key? key, required Widget child})`

Creates a `RemixTabBar` widget with this style applied.
