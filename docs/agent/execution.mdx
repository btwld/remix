A tool execution disclosure with output and copy or retry actions.

This is an [Open Code](/open-code) component: it installs into your application,
not as a separate Agent runtime package. The names below assume prefix `Ui`.

## Install

In a Flutter application with the project-local CLI configured:

```shell
dart run remix_cli:remix init --prefix Ui --preset fortal
dart run remix_cli:remix add execution_recipe
```

Use `--preset vanilla` when initializing a Vanilla-preset application. Do not
reinitialize an existing application with a different preset. Installing
`execution_recipe` includes its component and required theme/control dependencies.
Use `add execution` instead when you want the bare component and will provide styles.

Import `ui/ui.dart` from your application and use the scope for your preset:

- **Fortal:** `UiScope(child: ...)`.
- **Default:** `UiThemeScope(theme: const UiThemeData.light(), child: ...)` (or
  `UiThemeData.dark()` for a dark theme).

## Behavior

Supply `tool`, `title`, and host-rendered output through `child`. Use `UiExecutionStatus.running`, `.success`, `.error`, or `.cancelled`. Copy and retry callbacks perform application actions; rendering this component does not execute a tool. `collapseOnComplete` controls lifecycle-driven collapse; controlled `expanded` state remains host-owned.

## Recipe bundle

`uiAgentExecutionRecipe()` returns these styles:

| Bundle field | Style type |
|---|---|
| `style` | `UiExecutionStyler` |
| `surfaceStyle` | `CardStyler` |
| `disclosureStyle` | `DisclosureStyler` |
| `copyStyle` | `IconButtonStyler` |
| `retryStyle` | `IconButtonStyler` |

Pass the bundle's styles to the corresponding component parameters. Each
factory accepts same-named overrides, merged after the preset defaults.
Child-control styles must be passed through unchanged so hover, focus, and
disabled styles resolve in the child's context.

## Review and customize

The dashboard's **Workspace → Chat** demonstrates this surface alongside the
other Agent components. Its responses and tool activity are simulated locally.
Edit your installed source to customize it; `dart run remix_cli:remix add
execution_recipe --diff` previews authored-source differences without overwriting
local edits.
