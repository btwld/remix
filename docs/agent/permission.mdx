---
title: Permission migration
description: Move the previous permission surface to the package Agent widgets.
---

The previous `permission` and `permission_recipe` registry items have been replaced by
[Tool call](/agent/tool-call), using `package:remix/agent.dart`.
Previously installed source belongs to your app and keeps compiling until you replace or remove it.

Follow the [Agent migration guide](/agent/migrating) for the old-to-new map,
installation commands, and the change from prefixed widgets to package widgets.
