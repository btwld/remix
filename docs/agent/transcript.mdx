title: Transcript migration
description: Move the previous transcript surface to the package Agent widgets.
---

The previous `transcript` and `transcript_recipe` registry items have been replaced by
[Conversation](/agent/conversation), using `package:remix/agent.dart`.
Previously installed source belongs to your app and keeps compiling until you replace or remove it.

Follow the [Agent migration guide](/agent/migrating) for the old-to-new map,
installation commands, and the change from prefixed widgets to package widgets.
