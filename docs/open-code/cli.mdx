## Commands

Install editable Remix UI source.

```text
remix <command> [arguments]
```

| Option | Default | Description |
| --- | --- | --- |
| `--version` |  | Print the remix_cli version. |

For one command's help in a terminal, run `remix help <command>` or `remix <command> --help`; both print the same text.

```text
Get started:
  remix init          Pin the official registry and create lib/ui/ui.dart.
  remix list          See the items you can add.
  remix add button    Install an item and the items it needs.
```

### remix init

Initialize Remix source installation settings.

```text
remix init [options]
```

| Option | Default | Description |
| --- | --- | --- |
| `--prefix <Name>` | `Ui` | Type prefix for installed widgets, as in UiButton. |
| `--preset <name>` | `vanilla` | Design language for every installed item. One of `vanilla` (Neutral, minimal theme inspired by shadcn/ui), `fortal` (Fortal's own visual language), `heroui` (The look of HeroUI web 3.2.6). |
| `--ui-path <path>` | `lib/ui` | Directory for installed source and its ui.dart barrel. |

```text
Examples:
  remix init                                  Vanilla, Ui prefix, lib/ui.
  remix init --preset fortal --prefix Acme    Fortal preset, AcmeButton.
```

### remix list

List the items you can add from your registries.

```text
remix list [options]
```

| Option | Default | Description |
| --- | --- | --- |
| `--json` |  | Print the listing as JSON for scripts and agents. |

### remix add

Install registry items and their dependencies.

```text
remix add <item...> [options]
```

| Option | Default | Description |
| --- | --- | --- |
| `--dry-run` |  | Print the plan without running tools or writing files. |
| `--diff` |  | Show how installed source differs from the registry and write nothing. |
| `--exit-code` |  | With --diff, exit 2 when authored source differs, like git diff --exit-code. |
| `--overwrite` |  | Replace the named items with registry source. Installed dependencies are kept. |
| `--adopt` |  | Record verified legacy ownership without replacing source. |

```text
Examples:
  remix add button                       Install button and what it needs.
  remix add button card dialog           Install several items at once.
  remix add button --dry-run             Print the plan and change nothing.
  remix add button --diff --exit-code    Exit 2 on drift, for CI.
  remix add @acme/card                   Install from a registry you added.
```

### remix registry

Register and pin GitHub registry sources.

```text
remix registry <subcommand> [arguments]
```

```text
Examples:
  remix registry add @acme --repository acme/design   Pin its default branch.
  remix registry update @remix                        Re-pin to the newest stable commit.
  remix add @acme/card --diff                         Review what a moved pin changes.
```

#### remix registry add

Register a public GitHub registry and pin its commit.

```text
remix registry add <@namespace> --repository <owner/repo> [options]
```

| Option | Default | Description |
| --- | --- | --- |
| `--repository <owner/repo>` |  | Public GitHub repository that hosts the registry. |
| `--path <path>` | `registry` | Registry directory inside the repository. |
| `--ref <ref>` |  | Branch, tag, or commit to pin. Defaults to the default branch. |

#### remix registry update

Update one registry pin without changing installed source.

```text
remix registry update <@namespace> [options]
```

| Option | Default | Description |
| --- | --- | --- |
| `--ref <ref>` |  | Branch, tag, or commit to pin. Defaults to the ref in remix.yaml. |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Success, including help, version, dry-run, diff, and no-op reruns |
| `64` | Invalid command or arguments |
| `1` | Configuration, registry, dependency, process, generation, analysis, or filesystem failure |
| `2` | `add --diff --exit-code` found authored source that differs |
