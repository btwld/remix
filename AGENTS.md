# Remix

Flutter component library built on [Mix](https://github.com/btwld/mix)
(styling) and [Naked UI](packages/naked_ui) (behavior), plus `remix_cli`, which
installs editable design-system source into apps from GitHub-pinned registries.

repository does not commit installed skills; the index points at the sources.

- `using-remix`: app UI with `Remix*` widgets or an installed Vanilla/Fortal preset.
- `building-remix-design-system`: authoring a design system and publishing it as a registry.
- `mix`: stylers, specs, tokens, variants, animations, and modifiers.
- `releasing-a-package`: version bumps, contract checkers, release PRs, and tags.

Where the Mix skill and Remix differ, [canonical spellings](skills/using-remix/references/styling.md#canonical-spellings)
win: write `padding(.all(v))` and `borderRadius(.circular(x))`, not `paddingAll`
or `borderRounded`.

## Layout

- `packages/`: `remix` (components), `naked_ui` (headless behavior),
  `remix_cli` (installer), `remix_ui_icons`; each is versioned independently.
- `registry_source/`: private authoring source for the Vanilla and Fortal
  presets; never published.
- `registry/`: generated by `tool/build_registry.dart` from `registry_source/`.
  Do not hand-edit; run `dart run melos run open-code:registry:build`.
- `apps/`: `playground`, `demo`, and `dashboard` are dogfood consumers pinned in
  their `remix.yaml`; `docs` is the docs site; `naked_ui_example`.
- `docs/`: MDX documentation. `open_code/`: registry, preset, and release docs.
- `skills/`: published agent skills (`npx skills add btwld/remix`).
- `tool/`: contract checkers run by `ci:checks`.

## Commands

The Flutter SDK is pinned in `.fvmrc`; prefix commands with `fvm` when the
system SDK is older.

- `dart run melos bootstrap`
- `dart run melos run generate`: rerun `build_runner` in `remix` and
  `registry_source` after changing annotated sources.
- `dart run melos run ci:checks`: every contract checker, in seconds.
- `dart run melos run docs:check`: after editing `docs/` or `skills/`; rejects
  retired APIs and compiles published Dart examples.
- `dart run melos run ci`: the full local gate, matching CI.
