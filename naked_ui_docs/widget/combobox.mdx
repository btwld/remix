Use a combobox when users should type to filter choices. Keep the text controller, selected value and filtering in the caller. `NakedCombobox<T>` manages the option overlay, highlight, keyboard selection and semantics. `NakedComboboxOption<T>` supplies each option’s interaction state.

Keep option values stable across filtering. Dispose your text and focus controllers. Provide an accessible label for the editable field and a visible label for every option.
