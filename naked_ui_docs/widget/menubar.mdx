Use `NakedMenubar` for an application menu row. Supply menu anchors as children; the bar coordinates keyboard movement and opening between menus. Use `NakedMenubarScope` only when custom descendants need the shared menu context.

Build actions with `NakedMenuItem`, checkable actions with `NakedMenuCheckboxItem`, mutually exclusive actions with `NakedMenuRadioGroup`, and nested actions with `NakedMenuSubmenu`. Give each trigger an accessible label and retain Escape and focus restoration behavior.
